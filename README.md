# linkedin-articles

agilefactory 공동창업자 성민님의 링크드인 글 작업 저장소입니다.

- 규칙과 절차: [CLAUDE.md](CLAUDE.md)
- 지금 어떤 글이 어디까지 왔는지: [STATUS.md](STATUS.md)
- 글감: [backlog.md](backlog.md) · 발행 기록: [log.md](log.md)

## 사용법

Claude와 새 대화를 열고 글 ID로 시작하세요. 예: "TB-0 이어서", "새 글 시작".
Claude는 그 글의 `articles/<ID>/status.md`를 읽고 멈춘 단계부터 이어가며, 단계마다 커밋합니다.

원고(`draft.md`)는 성민님이 직접 씁니다.
